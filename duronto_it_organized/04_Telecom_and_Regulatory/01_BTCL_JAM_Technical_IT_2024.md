###### **How to represent binary tree using array** 

The general approach is to store the nodes of the binary tree in an array such that for any node at index i in the array: 

- Its left child is stored at index 2i+1 

- Its right child is stored at index 2i+2. 

Here's how you can represent a binary tree using an array: 

1. **Root Node** : Store the root node at index 0 of the array. 

2. **Left and Right Children** : For any node at index, its left child will be at index 2i+1 and its right child will be at index 2i+2. 

3. **Null Nodes** : If a node doesn't have a left or right child, you can represent it as a null value in the array. 

In the array representation, assuming that the tree is complete: 

- A will be at index 0. 

- B will be at index 1, C at index 2. 

- D will be at index 3, E at index 4, F at index 5, and G at index 6. 

A /   \ B     C / \     / \ D   E F   G 

So, the array representation of the tree would be: **[A, B, C, D, E, F, G]** . 

If any node is missing, you can represent it as null, so for example, if node F was missing, the array would be: **[A, B, C, D, E, null, G]** . 

This representation is particularly useful for complete binary trees, where every level, except possibly the last, is completely filled, and all nodes are as far left as possible.

**4 How can multiprogramming be achieved on a uniprocessor system?** **explain** 

Multiprogramming on a uniprocessor system can be achieved through a technique called time-sharing. In time-sharing, the CPU rapidly switches between executing multiple processes, giving the illusion of parallel execution. This is done by dividing the CPU time into small time slices and allocating each process a time slot during which it can execute. By rapidly switching between processes, the system gives the appearance of running multiple programs simultaneously. This allows for efficient utilization of the CPU and improved system throughput.

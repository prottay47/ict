1. 192.168.111.169/28 NA, BA, minimum host address and maximum host address. **Given IP:**  192.168.111.169/28

**Step 1: Subnet Mask** /28 means 28 bits for network.Subnet Mask = 255.255.255.240Block Size = 256 − 240 = 16

**Step 2: Determine Network Address (NA)** Subnet blocks increase by 16:0, 16, 32, 48, 64, 80, 96, 112, 128, 144, 160, 176, 192, 208, 224, 240

169 falls between 160 and 175.

**Network Address (NA):**  192.168.111.160

**Step 3: Broadcast Address (BA)** Next block starts at 176.So Broadcast Address = 175.

**Broadcast Address (BA):**  192.168.111.175

**Step 4: Valid Host Range** Minimum Host Address = 192.168.111.161Maximum Host Address = 192.168.111.174

**Final Answer:** NA = 192.168.111.160BA = 192.168.111.175Minimum Host = 192.168.111.161Maximum Host = 192.168.111.174Total Usable Hosts = 14

2. Write IPv4 Private IP address Range (Class A, B, C). **IPv4 Private IP Address Ranges**

Private IP addresses are reserved for internal network use and are not routable on the public Internet (as defined by RFC 1918).

**Class A:** 10.0.0.0 – 10.255.255.255(CIDR: 10.0.0.0/8)

**Class B:** 172.16.0.0 – 172.31.255.255(CIDR: 172.16.0.0/12)

**Class C:** 192.168.0.0 – 192.168.255.255(CIDR: 192.168.0.0/16)

**IPv4 Private IP Address Range**

Private IP address অভ্যন্তরীণ network ব্যবহারের জন্য নির্ধারিত এবং Internet-এ সরাসরি routable নয় (RFC 1918 অনুযায়ী)।

**Class A:** 10.0.0.0 – 10.255.255.255(CIDR: 10.0.0.0/8) **Class B:** 172.16.0.0 – 172.31.255.255(CIDR: 172.16.0.0/12) **Class C:** 192.168.0.0 – 192.168.255.255(CIDR: 192.168.0.0/16)

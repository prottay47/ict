**17. Convert binary 101011 into decimal.**   **Answer:**  43

**Explanation:**  Binary number-এর প্রতিটি digit 2-এর power নির্দেশ করে।

101011₂ = (1×2⁵) + (0×2⁴) + (1×2³) + (0×2²) + (1×2¹) + (1×2⁰)  = 32 + 0 + 8 + 0 + 2 + 1  =  **43**

**Related Info:**  • Binary → Base 2 • Decimal → Base 10 • Octal → Base 8 • Hexadecimal → Base 16

**Exam Tip:**  Binary → Decimal conversion-এ প্রতিটি bit-কে  **2-এর corresponding power**  দিয়ে গুণ করুন।

**28. If a − 1/a = 2, find a⁴ + 1/a⁴.**   **Answer:**  34

**Solution:**  Given, a − 1/a = 2

Squaring both sides:  (a − 1/a)² = 4  a² − 2 + 1/a² = 4  a² + 1/a² = 6

Again squaring:  (a² + 1/a²)² = 36  a⁴ + 2 + 1/a⁴ = 36  Therefore,  a⁴ + 1/a⁴ =  **34**

**29. What is the output?**

**Execution:**  i=0 → 2 i=1 → 3 i=2 → 4 i=3 → 5 i=4 → 6 i=5 → 7 i=6 → 8

3.Write a program which takes 'n' as input and calculates all the odd numbers up to n:
```
#include <stdio.h>
#include <math.h>
int main() {
int i, sum = 0;
printf("Enter the Value of N: \\n");
scanf("%d", &n);
printf("The Odd Numbers are: \\n");
for (i = 1; i <= n; i++) {
if (i % 2 != 0) {
printf("%d ", i);
sum += i;
}
}
printf("\\nThe Sum of Odd Numbers up to %d: %d\\n", n, sum);
return 0;
}
```

**Output:**

Enter the Value of N: 10The Odd Numbers are: 1 3 5 7 9The Sum of Odd Numbers up to 10: 25

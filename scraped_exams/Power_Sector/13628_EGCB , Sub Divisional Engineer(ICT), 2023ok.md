1.Write down the step of SDLC?

**SDLC**  is a structured process used to develop, maintain, and improve software in a systematic and efficient way.

**Phases of SDLC**

- **Planning & Requirement Analysis:**  Collect and analyze requirements, check feasibility, identify risks.
- **Defining Requirements:**  Requirements are documented in  **SRS (Software Requirement Specification)** .
- **Designing:**  System design is prepared using  **DDS (Design Document Specification)** .
- **Development:**  Coding is done using programming languages like C++, Java, Python.
- **Testing:**  Software is tested to find and fix errors and ensure quality.
- **Deployment & Maintenance:**  Software is released and later maintained with updates and bug fixes.

**SDLC**  হলো একটি structured process যা software develop, maintain এবং improve করার জন্য ব্যবহৃত হয়।

**SDLC-এর ধাপসমূহ**

- **Planning & Requirement Analysis:**  Requirement সংগ্রহ ও বিশ্লেষণ করা হয়, feasibility যাচাই এবং risk নির্ধারণ করা হয়।
- **Defining Requirements:**  Requirement গুলো  **SRS (Software Requirement Specification)** -এ document করা হয়।
- **Designing:**  System design  **DDS (Design Document Specification)** -এর মাধ্যমে তৈরি করা হয়।
- **Development:**  C++, Java, Python ইত্যাদি language ব্যবহার করে coding করা হয়।
- **Testing:**  Software test করে error খুঁজে বের করা এবং ঠিক করা হয়।
- **Deployment & Maintenance:**  Software release করা হয় এবং পরে update ও bug fix করা হয়।

3.What is CIA Triad?

The  **CIA Triad**  is a fundamental model in information security that defines three main goals:  **Confidentiality, Integrity,**  and  **Availability** .

- **Confidentiality:**  Ensures that information is accessed only by authorized users using techniques like encryption and access control.
- **Integrity:**  Ensures that data remains accurate and is not modified by unauthorized users using methods like hashing and digital signatures.
- **Availability:**  Ensures that systems and data are accessible to authorized users when needed using backups, redundancy, and recovery systems.

**CIA Triad**  হলো information security-এর একটি গুরুত্বপূর্ণ model যা তিনটি প্রধান লক্ষ্য নির্ধারণ করে:  **Confidentiality, Integrity**  এবং  **Availability** ।

- **Confidentiality:**  এটি নিশ্চিত করে যে তথ্য শুধুমাত্র authorized user-ই access করতে পারে, যেমন encryption এবং access control ব্যবহার করে।
- **Integrity:**  এটি নিশ্চিত করে যে data সঠিক থাকে এবং unauthorized user দ্বারা পরিবর্তিত হয় না, যেমন hashing এবং digital signature ব্যবহার করে।
- **Availability:**  এটি নিশ্চিত করে যে system এবং data প্রয়োজনের সময় authorized user-এর জন্য available থাকে, যেমন backup, redundancy এবং recovery system ব্যবহার করে।

4.  What is Database?

A  **database**  is a structured collection of data that is stored and managed in a way that makes it easy to access, update, and organize.

Data in a database is typically stored in  **tables** , which consist of  **rows**  (records) and  **columns**  (fields). Indexing and other techniques are often used to optimize searching and retrieving specific information quickly.

5. What is BIOS?

**BIOS**  is a firmware program stored in a computer’s motherboard that initializes hardware and starts the booting process when the computer is powered on.

- **Function:**  It checks and initializes hardware components like CPU, RAM, and storage devices.
- **Boot Process:**  It loads the operating system into memory during startup.
- **Location:**  Stored in ROM or flash memory on the motherboard.
- **POST:**  Performs  **Power-On Self-Test (POST)**  to ensure hardware is working properly.

**BIOS**  হলো একটি firmware program যা computer-এর motherboard-এ সংরক্ষিত থাকে এবং computer চালু হলে hardware initialize ও boot process শুরু করে।

- **Function:**  এটি CPU, RAM এবং storage device-এর মতো hardware component পরীক্ষা ও initialize করে।
- **Boot Process:**  এটি startup-এর সময় operating system memory-তে load করে।
- **Location:**  এটি motherboard-এর ROM বা flash memory-তে সংরক্ষিত থাকে।
- **POST:**  এটি  **Power-On Self-Test (POST)**  চালিয়ে hardware ঠিকভাবে কাজ করছে কিনা তা পরীক্ষা করে।

6. Full meaning of: HTTPS

**HTTPS (HyperText Transfer Protocol Secure)**

**HTTPS**  is a secure version of  **HTTP**  used for communication over the internet. It ensures that data transferred between a user and a website is encrypted and protected.

- **Security:**  Uses  **SSL/TLS**  protocols to encrypt data.
- **Data Protection:**  Prevents hackers from intercepting sensitive information like passwords or credit card details.
- **Authentication:**  Verifies that the website is genuine and not a fake one.
- **Usage:**  Widely used in secure websites like banking, e-commerce, and login systems.
